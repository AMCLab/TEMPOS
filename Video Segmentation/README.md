Results* for running deepsort_video.ipynb on a Poly Ethylene Glycate (PEG) polymers wrapped around DNA, on an in situ liquid cell from DENS Ocean liquid holder and acquired on a JEOL 2200 with a K2 IS detector in counting mode. The video consists of 110 frames at a 5 fps rate (frames per second).

\* The video is in 2x speed to fit in as github media

The model for particle detection is a mask-rcnn model with 50 layers trained with detectron2, on fully synthetic data created using TEMPOS.
